🎮 GameZone Retro
Landing page simples e objetiva para a GameZone Retro, uma loja focada na venda de jogos e consoles clássicos.

📌 Sobre o Projeto
O projeto é uma página institucional estática desenvolvida para apresentar a loja, listar os consoles suportados e exibir uma tabela com a lista de jogos disponíveis e seus respectivos preços.

🚀 Tecnologias Utilizadas
HTML: Estruturação da página e tabelas.
